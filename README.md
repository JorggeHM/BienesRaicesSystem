## BienesRaicesSystem es un proyecto creado basado en un curso de la plataforma Udemy

Se puso en practica
HTML, CSS, SASS, JS, PHP Y SQL

Arquitectura Spageti para un desarrollo rapido
Este proyecto busca únicamente realizar un repaso de las tecnologías básicas

Prendizajes obtenidos destacados
* CRUD system
* Conexion con DB
* diseno responsive
* Dark mode
* Inicios de sesion
* Despliegue dinamico de anuncios (en funcion a la cantidad de datos en la DB)

El sistema no tiene funciones de validacion en caso de ejecutarse sin la base de datos
